### Features
- I2C Speed: ~40 kHz (Standard Mode)
- MCU: Holtek HT66F0021
- LCD: 16×2, 20×4, 16×1 (configurable)
- I2C Addresses: 0x20-0x27 (8 possible)
- Memory: ~6 KB program, ~10 bytes RAM
- Production Ready: ✅ Tested on Hardware
